## 📌 프로젝트 개요
Elasticsearch의 내부 구조와 검색 동작 원리를 이해하고,<br>
단일 노드부터 클러스터 환경까지 확장하며<br>

단순 개념 학습을 넘어, 
실제 서비스 환경을 가정하여 확장성과 장애 대응까지 고려한 구조를 구현하는 것을 목표로 합니다.
